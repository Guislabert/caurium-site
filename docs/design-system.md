# Caurium 设计系统 · 共用骨架

> 实现文档。两个分支共用**结构、排版规则、组件行为与无障碍标准**；
> 只有配色、字体家族、圆角与阴影属于视觉体系，各自记录。

## 两套视觉体系

| 分支 | 体系 | 文档 | 视觉性格 |
| --- | --- | --- | --- |
| `main` | v1 editorial | [`design-system-editorial.md`](design-system-editorial.md) | 暖纸、navy 墨色、衬线标题、圆角、药丸按钮 |
| `dev` | v2 graphite | [`design-system-graphite.md`](design-system-graphite.md) | 冷灰、纯白面板、无衬线、直角、细线导轨 |

两份视觉文档在**两条分支上都存在**：它们记录的是可选体系，不是分支私有状态。
这样两条分支合并时文档不会产生 "added in both" 冲突。

两者共享下面的一切。改动共用部分时两边同时生效；改动视觉体系时只动对应那一份。

## 1. 设计命题（共用）

页面是一张可核查的技术面板。结构靠**线条、留白与字号层级**表达，不靠装饰。

- 状态由文字 + 形状表达，不依赖颜色单独传达。
- 等宽字体承担标签、编号、按钮与元信息。
- 每个数字、每条声明都要能追到 `src/content/` 里的记录。

## 2. Design tokens（共用部分）

以下令牌两套体系都有，**值各自不同**，见两份视觉文档。

| Token | 作用 |
| --- | --- |
| `--background` | 页面底色 |
| `--paper` | 卡片、图版、表头 |
| `--surface` | 面板头、次级底色 |
| `--surface-2` / `--surface-3` | 两个语义区块（原则 / 边界） |
| `--foreground` / `--ink` / `--ink-2` | 标题、深色区块、正文 |
| `--muted` | 次级文字 |
| `--border` / `--border-strong` | 细线与分隔线 |
| `--control-border` | **控件边界，必须对纸白 ≥ 3:1**；`--border-strong` 是装饰线，不能兼任 |
| `--accent` / `--accent-ink` / `--accent-soft` | 强调色；`--accent-ink` 用于浅色面上的可读文字与焦点环（≥ 7:1） |
| `--lime` / `--lime-soft` / `--olive` | 品牌标记点与其底色上的文字 |
| `--success` / `--warning` / `--danger` | 仅承载真实状态 |
| `--container` | 内容宽度 |
| `--radius-card` / `--radius-control` | 卡片与控件圆角 |
| `--header` | 固定页头高度 |

**纪律**：新增颜色必须先成为令牌，不得在组件里写字面值。

## 3. 排版规则（共用）

字体家族不同，但层级逻辑相同：

| 角色 | 字号 | 行高 | 字距 |
| --- | --- | --- | --- |
| Display H1 | `clamp(2.75rem, 5.6vw, 4rem)` | 1.04 | −0.035em |
| Hero H1 | `clamp(2.6rem, 5vw, 3.9rem)` | 1.05 | −0.035em |
| Page H1 | `clamp(2.3rem, 4.6vw, 3.4rem)` | 1.06 | −0.032em |
| H2 | `clamp(1.9rem, 3.4vw, 2.75rem)` | 1.08 | −0.03em |
| H3 | 19–24px | 1.2 | −0.02em |
| Body | 16px | 1.55 | 0 |
| Lede | 16–18px | 1.6 | 0 |
| 标签 / 按钮 / 元信息 | **≥ 11px** | 1.5 | 0.06em，全大写 |
| 代码 | 12.5px | 1.7 | 0 |
| 词标 | 18px | 1 | −0.02em |

- **功能性文字不低于 11px**（链接、按钮、导航、标签、表格单元、元信息）。低于此值在高 DPI 与小视口上退化；把它加进字号阶梯不算豁免。
- 正文不小于 12px；正文段落不小于 14px。
- 全大写只用于短标签、编号、按钮与导航，不用于整句。
- 行宽：正文段落 `max-width` 控制在 34em 左右（约 75 字符）。**不要用 `ch`** —— `ch` 按父元素字体解析，会给出意外宽度；用 `rem` 或 `em`。
- 标题之上不放 kicker / eyebrow 小标签：标题自己承担层级。序号前缀（`01 /`、`P.01`）仅在顺序本身是信息时保留。

## 4. 布局（共用）

- 桌面 12 列，间距 24px；区块 64 / 88 / 104px。
- Hero：深色全宽区块，居中窄栏正文（`max-w-3xl`），下方放 `Fig. 01` 模块图 + 状态条。
- 分栏区块：`0.72fr / 1.28fr` 等左侧标题、右侧列表。
- 卡片网格用 `gap: 1px` + 底色作分隔线；**不要**用「带边框的容器 + gap 透色」，那会读成卡片套卡片。
- 文档页：200px 导航 + 约 640px 正文 + 176px TOC（≥1280px）。

## 5. 组件行为（共用）

### 5.1 Logo
标志：方块 + C 形弧线 + 标记点，颜色从令牌读，不写字面值。深色背景用反色变体。词标用 `.wordmark`。

### 5.2 按钮
高度 ≥ 46px，等宽字体，全大写。hover 只改背景/边框/文字色，**不做位移**。focus-visible 用 2px 强调色外框，且对比度 ≥ 3:1。

### 5.3 状态徽章
文字 + 圆点/空心点，不只依赖颜色。`Planned` 中性；`Private preview` 强调色；只有 `Available` 可使用 success 色。**功能性文字 ≥ 11px**。

### 5.4 卡片
1px 边框，圆角见各视觉文档，无常态阴影。hover 只改边框与箭头位移。整卡可点击时链接覆盖整卡，保证键盘可达。

### 5.5 图版（Figure）
头部为面板底色 + 等宽大写标题；顶部 `FIG. 0X — TITLE` + 状态徽章；底部说明 + `Rev.`/`Illustrative`。图内标注最小 10px，不承载正文。

### 5.6 文档
正文最大 34em；H2 前距 40px、H3 前距 28px。表头用等宽大写小字。代码块支持复制且 `tabIndex=0` 可键盘滚动。左侧导航 sticky，当前页有视觉标记；右侧 TOC 仅 ≥1280px。

### 5.7 页脚
上边框；左侧 Logo + 定位句 + 阶段说明，右侧链接组。分组标题用等宽大写小字。

### 5.8 状态页
未接入时显示明确说明，不显示绿色或百分比。`checkedAt` 新鲜度优先于 `generatedAt`。

## 6. 响应式（共用）

360、390、768、1024、1440px。360 无横向滚动、按钮全宽；768 产品卡两列、桌面导航出现；1024 文档左导航竖排；1440 容器居中。

## 7. 无障碍（共用）

- 跳过导航链接；一页一个 H1，heading 顺序不跳级。
- 菜单 `aria-expanded`、Escape 关闭、焦点返回触发按钮。
- 图示有 `role="img"` + `aria-label` 或可见文本替代。
- 正文对比度 ≥ 4.5:1；控件边界 ≥ 3:1；浅色面上的链接用 `--accent-ink`，不用浅强调色作正文色。
- `prefers-reduced-motion`：**缩短动的部分，保留颜色与不透明度的状态反馈**。不要用 `transform: none` 一刀切——跳过链接与移动导航靠 `translate` 定位会被挤到屏幕外。
- 不依赖 hover 才能访问内容；关闭 JavaScript 后正文、导航与链接仍可读。

## 8. 性能预算（共用）

首屏无背景视频、无大图、无第三方脚本。字体自托管，只加载实际字重。内联 SVG。目标：移动端 Lighthouse Performance ≥ 90，Accessibility/SEO ≥ 95。
